## Respostas  

---

1. Paradigma de programação quer dizer a forma que manipulamos e desenvolvemos os algoritmos utilizar para a solução de um problema. 
 
2. Paradigma Procedimental; Paradigma Funcional; Paradigma Orientado a Objetos. 
  
3. É criar algoritmos baseados em objetos reais, desenvolvendo seus comportamentos e características. As vantagens são: associamos objetos reais em códigos e criamos funções para seus comportamentos, logo fica organizado. 
  
4. É buscar um estrutura lógica intrínseca ao objeto. 
  
5. É o formato que o objeto teria, tendo os seus atributos(características) e os seus métodos(comportamentos).

1. Atributo de instância: é o nome do aluno. Cada aluno tem o seu, diferente dos outros.
Atributo estático: é o nome da escola. Todos os alunos pertencem à mesma escola, esse valor é compartilhado.

2. Porque atributos privados protegem o estado interno do objeto e impede que código externo o modifique, sem sabermos.

3. Qualquer parte do código poderia ler e modificar os dados diretamente.

4. O construtor, confirma e faz o requerimento dos dados necessários para funcionamento.

5. O encapsulamento faz um isolamento dentro da classe.

## Respostas

### Questão 1

#### Classe Abstrata 
- Objetivo: ser uma base que não pode moldar um objeto, entretanto pode moldar as classes que herdam metodos e atributos dela;

- Instanciação: não é diretamente instanciado;

- Métodos: pode-se criar e utilizar o abstract no método para as classes filhas utilizarem; 

- Atributos: pode-se criar;

- Herança: ela é o que as classes herdam quando usado extends.

#### Interface
- Objetivo: organização de métodos que vão ser especializados pelas classes e atributos constantes;

- Instanciação: não é diretamente instanciado;

- Métodos: são criados os métodos dentro dele assim os métodos podem ser sobrescritos dentro das classes;

- Atributos: só se criam constantes;

- Herança: pode ser usado o extends junto ao implements e herdar varias interfaces limitando-se a uma classe, mas o implements por si só ja pode colocar diversas interfaces. 

### Questão 2
( V ) Uma classe abstrata pode possuir métodos concretos.


( V ) Uma interface pode possuir métodos default.


( F ) Uma classe pode herdar de várias classes abstratas.


( V ) Uma classe pode implementar várias interfaces.


( V ) Uma interface pode possuir constantes.
